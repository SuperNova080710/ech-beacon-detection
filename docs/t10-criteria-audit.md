## 제출용 ZIP 별도 폴더 검증 (2026-10-20 · 사용자 제공 터미널 출력)

- ZIP 파일: `T10-Orion-main-v1-reproduction.zip`
- 파일 크기: **1,883,864 bytes** (보수적 제한 8,000,000 bytes 이하, 여유 6,117,126 bytes)
- 검증 방법: 제출자 로컬에서 별도 폴더에 압축 해제 후 `python3 verify_submission.py` 실행
- SHA-256 대상: **465개 파일** (실행 로그의 `PASS: package files and SHA-256 (465 files)` 기준)
- Raw Manifest 200건 / Flow Metadata CSV 200건, Trial당 HTTPS 연결 30개 검증
- Features 및 Labels 200개 고유 Trial 검증
- Held-out Prediction에서 TP/FP/TN/FN을 재계산하고 보존된 평가 JSON과 일치 확인
- 변조 방지용 고정 main-v1 원본 5개 파일의 SHA-256 확인
- 최종 출력: `PASS: T10 ZIP offline verification complete`

사용자가 제공한 터미널 출력은 위 항목 모두 PASS를 보고한다. **실제 ZIP 파일을 본 문서 작성자가 직접 받아 동일 바이트의 SHA-256으로 독립 대조한 것은 아니다.** 업로드 후 파일 선택과 ALEPH 접수, 선택 URL의 시크릿 창 접근은 별도 확인이 필요하다. ZIP에서 검증한 것은 원자료·분류결과·체크섬의 오프라인 재현이며, ECH 200 Trial 재수집/PCAP 전체 재추출/모델 재학습을 완료했다는 의미가 아니다.

## 과장 없이 남겨야 할 쟁점

- **후보 선정:** 부록 A에서 다섯 관심 분야는 확인되지만 탈락 후보 각각의 이유와 가설 조정 대화의 원문은 현재 근거가 부족하다. 실제 기억이나 기록으로 확인할 수 있는 부분만 *사후 회고*로 작성하고, 당시 작성한 실험 전 기록인 것처럼 소급하지 않는다.
- **논문 가설:** 높은 지터 Recall 우위는 지지되지 않았고 Multi-feature의 개선은 같은 60개 정상 표본의 FP 3건 감소에서 관찰되었다.
- **원자료:** 200개 PCAP은 Release에 별도 보존하되 납품 ZIP에는 Raw Manifest 200개와 Flow Metadata CSV 200개 및 처리·평가 절차를 실제로 포함한다.
- **재현 범위:** 제출 ZIP의 검증 스크립트는 Raw 건수, 체크섬 및 고정 Prediction의 평가 지표 재계산을 수행한다. PCAP 재수집이나 전체 모델 재학습 완료로 표현하지 않는다.
- **참고문헌:** 본문 인용과 서지를 정합화했다. 공식 원문 출처의 최종 URL 및 이슈 시점 정보는 제출 전 별도로 점검한다.
- **웹 URL:** GitHub/Release 링크에 대한 시크릿 창 접근은 현재 접속 정보만으로 검증했다고 단정하지 않는다.

2. **보완:** C02/C03/C09의 실제 주제 선정 과정 증거 확인. 사후 회고는 당시 기록과 구분하며 허위 소급 작성하지 않음.
3. **미확인:** 선택 URL을 신규 시크릿 창에서 비로그인·무인증 접근할 수 있는지 확인(C51).
4. **미완료:** 최종 ZIP SHA-256 별도 기록, 플랫폼 재현·통과 확인 4항목과 AI·직접 판단 3줄 작성, ALEPH에 최종 ZIP **하나** 실제 업로드 후 접수 확인.
