## 출처 확인 원칙

- RFC는 RFC Editor 공식 원문을 기준으로 한다.
- Internet-Draft는 IETF Datatracker 최신 revision을 기준으로 하며 확정 표준으로 표현하지 않는다.
- 학술 논문은 출판사 원문 또는 DOI 메타데이터에서 저자, 연도, 저널, 권·호, 페이지 또는 article number, DOI를 확인한다.
- 공개 데이터셋은 Zenodo record와 version 정보를 기준으로 한다.
- 검색 결과 요약만으로 참고문헌 정보를 확정하지 않는다.
